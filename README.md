# Energy Systems Wiki

> **能源系统工程知识库**  
> 从暖通空调出发，理解能源系统。

Energy Systems Wiki 是一个面向工程师、科研人员与技术管理人员的开放工程知识平台，系统整理能源科学基础、暖通空调与制冷、建筑能源、系统控制、工程案例、计算方法与技术前沿，建立连接 **基础理论 → 工程技术 → 系统实践 → 科研创新** 的知识体系。

## 项目定位

本项目以能源系统为长期边界，以暖通空调（HVAC）、制冷与热泵为当前重点知识域，并逐步扩展到建筑能源、储能、可再生能源、能源管理、数字孪生与智能控制等方向。

知识内容强调四个层次：

1. **What｜是什么**：概念、对象与系统边界；
2. **Why｜为什么**：物理机理、热力过程与因果链；
3. **How｜怎么做**：设计、选型、控制、仿真与工程方法；
4. **What Next｜还能如何优化**：性能边界、工程权衡与研究问题。

## 知识体系

- **基础科学 Fundamentals**：工程热力学、传热学、流体力学、传质与湿空气、自动控制、数值计算；
- **暖通与制冷 HVAC & Refrigeration**：制冷循环、压缩机、换热器、节流装置、制冷剂、冷水机组、热泵、水系统与风系统；
- **能源系统 Energy Systems**：建筑能源、综合能源、储冷储热、余热利用、可再生能源与区域能源；
- **控制与智能 Control & Intelligence**：传感器、执行器、PID、BMS、IoT、边缘计算、CPS、数字孪生、MPC 与 AI；
- **工程案例 Engineering Cases**：基于公开资料的设计、改造、运行优化、调试与故障分析案例；
- **技术前沿 Frontier & Insights**：前沿论文、工程争议、研究方法、技术趋势与开放问题。

## 信息公开与知识产权原则

本仓库是**公开知识仓库（public-safe repository）**。进入本仓库的内容应默认可能被搜索引擎、同行以及大语言模型读取与索引。

允许收录：

- 公开教材、国家/行业标准与规范中的可合理引用内容；
- 已公开发表的论文、技术报告和公开数据；
- 厂商已经公开发布的产品与技术资料；
- 来源清楚的公开工程案例；
- 作者基于公开信息形成的原创工程分析与技术总结。

禁止收录：

- 企业内部图纸、BOM、成本、供应商及采购信息；
- 未公开设备参数、性能曲线、测试数据和控制程序；
- 客户名称、项目地址、联系人及其他敏感信息；
- 内部算法、控制阈值、调试记录及未经授权的技术文件；
- 任何无法确认公开授权边界的原始企业资料。

具体规则见 [`docs/about/publication-policy.md`](docs/about/publication-policy.md) 与 [`SECURITY_REVIEW.md`](SECURITY_REVIEW.md)。

## v0.1 建设重点

第一阶段优先完成暖通空调与制冷基础知识骨架，包括：

- 制冷循环与湿空气基础；
- 压缩机、换热器、节流装置与制冷剂；
- 冷水机组、热泵及典型水系统；
- HVAC 自动控制基础；
- 公开工程案例与工程思考；
- 面向后续建筑能源与智能能源系统的学习路线。

## 本地运行

```bash
npm install
npm run docs:dev
```

构建静态站点：

```bash
npm run docs:build
npm run docs:preview
```

## 技术栈

- [VitePress](https://vitepress.dev/)：静态技术文档与知识站点；
- Markdown：知识内容源文件；
- TypeScript / Vue：主题与交互扩展；
- Git / GitHub：版本管理、协作与审阅；
- GitHub Pages：公开网站部署。

## 语言规范

正文以中文为主。专业术语首次出现时，优先采用“**中文名称（English Full Name，ABBR）**”的形式；目录、文件名、URL 与代码统一使用英文，以兼顾中国工程师的阅读习惯与工程维护的一致性。
