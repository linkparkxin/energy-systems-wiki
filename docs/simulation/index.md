# 仿真与设计

仿真应由工程问题决定模型层级：

- 估算整机能效时，优先使用一维热力模型；
- 研究风场、布水和局部压降时，使用计算流体力学（Computational Fluid Dynamics，CFD）；
- 研究建筑全年负荷时，使用建筑能源模拟；
- 研究运行策略时，将部件模型与控制模型耦合。

## 推荐流程

实物与图纸识读 → 参数和边界条件 → 一维部件模型 → 局部CFD → 整机能效与控制模型 → 测试或公开数据校核

模型必须保留输入、假设、物性数据、软件版本和验证记录。工具不能替代边界条件和实验校核。
