# 答疑归档

本页收录经过管理员核验、整理和版本化发布的工程问答。原始问题和讨论保留在 GitHub Issue 中，正式答案以本知识库的 Markdown 页面为准。

## 已归档内容

### 制冷与热泵工程答疑

覆盖以下基础问题：

- 蒸发温度和冷凝温度对制冷循环的影响；
- 制冷剂不足的系统表现与联合诊断；
- 膨胀阀开度过大或过小的典型现象；
- 回气过热度、排气过热度及其测量方法；
- 空调制冷评价工况与冷水机组典型工况的区别；
- 过冷度、过热度对制冷量、压缩机安全和系统能效的影响。

阅读：[13 工程答疑区](/knowledge/refrigeration/13-field-faq)。

## 归档规则

只有满足以下条件的问题，才适合进入正式知识库：

1. 问题具有可迁移的工程学习价值，而非只适用于单个项目；
2. 内容经过公开资料、基础理论或可复现计算核验；
3. 已删除客户信息、内部参数和其他敏感内容；
4. 公式、变量、单位、示例和适用边界已经说明；
5. 由管理员通过 Git 提交发布，并保留可追溯的修改记录。

对于尚未核验的问题，请进入[交流与问答](/community/)提交，不要把未经确认的现场判断直接写入正文。
