# 交流与问答

这里是面向所有读者的开放式讨论区。你不需要 GitHub 账户，也不需要先经过管理员审核，即可发起问题、回答他人的问题或补充工程经验。

讨论区采用“即时参与、事后治理”的方式：

- 普通用户可以创建问题、回复和补充说明；
- 回复会直接显示，便于形成连续讨论；
- 管理员只负责删除违规、泄密、垃圾或明显不适合公开的内容；
- 管理员不负责逐条审核，也不要求管理员回答每个问题；
- 具有长期学习价值的内容，后续再由维护者整理为正式 Markdown 页面并提交 Git。

> 请勿填写客户名称、项目地址、内部图纸、BOM（Bill of Materials，物料清单）、未公开参数、报价、账号或其他敏感信息。

## 开放式讨论区

你可以围绕以下方向进行交流：

- 制冷、热泵、压缩机、换热器和节流部件；
- 冷冻水、冷却水、空气处理和建筑能源系统；
- 控制、BMS（Building Management System，建筑设备管理系统）、IoT（Internet of Things，物联网）和仿真；
- 公式推导、计算示例、图片表达和页面勘误；
- 工程现象、故障判断和学习方法。

## 如何参与答疑

### 发起问题

请尽量写清楚问题背景、现象、已知条件和单位。涉及制冷系统时，建议说明运行模式、蒸发压力、冷凝压力、供回水温度、空气温度、流量和测点位置。

### 回复问题

回复可以补充原理、公式、计算示例、公开资料或工程经验。对于尚未确认的判断，请注明适用条件，不要把单一项目经验直接表述成普遍规律。

### 修订自己的观点

为了保留讨论过程，建议通过追加回复说明修订内容，不要反复覆盖原留言。这样其他读者可以看到问题是如何被澄清的。

## 管理员的最终权限

管理员只承担事后治理责任：

- 删除涉及企业机密、个人隐私、客户资料或安全风险的内容；
- 删除广告、恶意攻击、重复刷屏和明显垃圾信息；
- 保留正常的不同意见和未完成的技术讨论；
- 必要时在删除位置保留“内容已由管理员移除”的记录；
- 不替代参与者回答一般技术问题。

管理员删除的是公开显示权限，不应随意改变讨论事实。正式内容的修订仍应通过 Git 提交完成。

## 正式知识如何归档

讨论区中的内容不会自动改写知识库正文。对于具有普遍学习价值的问题，维护者可以在取得讨论共识后：

1. 提取问题和主要观点；
2. 删除内部项目细节；
3. 使用公开资料或可复现计算进行核验；
4. 按知识库的中英文术语、公式和变量规范重写；
5. 提交到对应章节或[答疑归档](/community/qa-log)；
6. 通过 Git commit 留下正式版本。

目前已有的制冷与热泵答疑可阅读：[制冷与热泵工程答疑](/knowledge/refrigeration/13-field-faq)。

## 外部贡献入口

如果你希望直接参与 Markdown、图片或代码维护，可以使用 GitHub 的[内容建议或勘误表单](https://github.com/linkparkxin/energy-systems-wiki/issues/new?template=content-feedback.yml)。普通留言和技术讨论无需 GitHub 账户，直接使用上方讨论区即可。

本栏目只提供公开工程知识交流，不替代设备厂家说明书、现场安全规程、法定标准或专业人员的现场判断。
