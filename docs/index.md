## 为什么建设这个知识库？

能源系统工程横跨热力学、传热传质、流体、制冷、建筑环境、自动控制和数据科学。工程实践中的很多问题，无法仅靠单一设备参数解释，需要把**设备、负荷、环境、控制和能源流**放在同一个系统边界下理解。

Energy Systems Wiki 试图建立一套适合中国工程师与科研人员长期使用的开放知识结构。内容不追求简单堆积资料，而强调从“是什么”进一步进入“为什么、怎么做、还能如何优化”。

## 推荐阅读路径

**入门理解：** 基础科学 → 制冷与热泵 → HVAC 系统 → 工程案例  
**工程设计：** 负荷与边界 → 系统选择 → 设备与管网 → 控制 → 调试与评价  
**仿真优化：** 物理基础 → 建模 → CFD / 能源模拟 → 校核 → 优化  
**智能能源：** HVAC → 自动控制 → BMS → IoT → 边缘计算 → 数字孪生 → MPC / AI

## 内容原则

本站优先使用公开教材、标准规范、论文、公开技术资料和公开工程案例。任何可能涉及企业知识产权、客户信息、未公开设备参数、内部算法和工程敏感数据的内容，不进入公开仓库。

详细要求见 [信息公开与发布规范](/about/publication-policy)。
