## 为什么建设这个知识库？

暖通空调工程并非单一设备知识的集合。一个真实系统同时涉及工程热力学、传热学、流体力学、制冷循环、空气处理、换热设备、自动控制以及能源利用。设备参数只能解释“它是什么”，完整的工程分析还需要进一步回答“为什么这样设计”“不同设备如何组成系统”“系统在不同工况下如何运行”以及“如何验证和优化”。

HVAC & Energy Systems Wiki 希望建立一套从基础科学、制冷与热泵、设备部件、机组系统、控制智能到能源优化和工程验证逐级展开的工程知识体系。内容以公开标准、公开文献、基础理论和可公开工程案例为主要依据，并通过计算、仿真和实验方法形成可以复现和持续维护的技术知识。

## 知识体系主线

**基础科学 → 制冷与热泵 → 设备与部件 → 机组与系统 → 控制与智能 → 能源优化 → 工程验证与技术前沿**

## 推荐阅读路径

**入门理解：** 基础科学 → 制冷与热泵 → 暖通系统 → 工程案例  
**工程设计：** 负荷与边界 → 系统选择 → 设备与管网 → 控制 → 调试与评价  
**仿真优化：** 物理基础 → 建模 → CFD / 能源模拟 → 校核 → 优化  
**智能能源：** HVAC → 自动控制 → BMS → IoT → 边缘计算 → 数字孪生 → MPC / AI

## 内容原则

本站优先使用公开教材、标准规范、论文、公开技术资料和公开工程案例。任何可能涉及企业知识产权、客户信息、未公开设备参数、内部算法和工程敏感数据的内容，不进入公开仓库。

详细要求见 [信息公开与发布规范](/about/publication-policy)。
