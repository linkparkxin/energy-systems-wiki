# 供应链管理 · Supply Chain Management

本专栏用于建立暖通空调与能源系统工程相关的供应链管理入口，暂不展开具体企业流程和供应商数据。

## 计划方向

- 供应商识别、准入与技术协同；
- 采购需求、交付计划与库存控制；
- 设备、部件与材料的质量追溯；
- 项目现场物流、安装配合与交付；
- 风险识别、替代方案与持续改进。

## 公共内容边界

公开页面只讨论可泛化的供应链方法、质量管理与工程协同原则，不发布供应商名单、报价、合同、成本、客户项目数据或未公开采购信息。
