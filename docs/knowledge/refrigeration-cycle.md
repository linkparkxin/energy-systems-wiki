# 02 制冷与热泵 · Refrigeration & Heat Pumps

本章是知识库从基础科学进入设备与系统的桥梁。学习重点不是记忆四大件名称，而是理解热量、功、制冷剂状态、换热温差和系统能效之间的因果关系。

## 本章学习主线

**物理基础 → 制冷剂状态 → 蒸气压缩循环 → 温度与压力 → 过热过冷 → p-h / T-s 图 → 性能评价 → 变工况 → 运行诊断 → 热泵循环 → 工程答疑**

## 学习要求

建议先完成第 00—03 节，再进入温度、过热过冷和性能评价。阅读过程中应同步建立三张表：

1. 状态点表：记录压力、温度、焓、熵、干度或过热状态；
2. 能量表：记录蒸发吸热、压缩功、冷凝放热和辅助功耗；
3. 诊断表：记录测量值、偏差方向、可能原因和验证方法。

第 13 节适合作为学习完第 04—11 节后的现场复习入口，用于把单个参数放回完整的制冷循环中判断。
