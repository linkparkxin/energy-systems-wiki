# 从制冷循环开始

## 一句话理解

蒸气压缩制冷循环通过压缩机、冷凝器、节流部件和蒸发器的连续配合，把低温侧的热量搬运到高温侧。设备能效取决于四个部件以及空气侧、水侧、控制和负荷之间的共同状态。

## 四个基本过程

| 环节 | 制冷剂主要状态 | 主要作用 |
| --- | --- | --- |
| 压缩 | 低压气体变为高压气体 | 提高压力和温度 |
| 冷凝 | 高压气体逐步变为液体 | 向环境释放热量 |
| 节流 | 高压液体变为低压两相流 | 降低压力和饱和温度 |
| 蒸发 | 低压液体吸热汽化 | 从被冷却对象吸收热量 |

真实机组还会涉及过热、过冷、回油、气液分离、除霜、热回收和旁通等过程。因此，四大件是理解主循环的入口，不是完整机组模型。

## 压力为什么会影响温度？

纯制冷剂在一定压力下具有对应的饱和温度。压缩机提高压力后，饱和温度升高，制冷剂更容易向环境放热；节流部件降低压力后，饱和温度下降，制冷剂可以在蒸发器中吸热。

过热度和过冷度还受到换热面积、制冷剂流量、环境温度、控制策略和管路换热的共同影响。

## 能效如何计算？

制冷量可以表示为：

$$
Q_e = \\dot m_r(h_{out,e}-h_{in,e})
$$

机组综合能效应纳入压缩机、风机、水泵和控制设备：

$$
COP_{system} =
\\frac{Q_e}
{P_{compressor}+P_{fan}+P_{pump}+P_{aux}}
$$

降低冷凝温度通常有利于降低压缩机功耗，但过大的风量、喷水量或泵功率可能抵消部分收益。

## 工程判断顺序

1. 明确热量从哪里被吸收、最终排向哪里；
2. 确认制冷剂在每个部件中的状态变化；
3. 查看压力、温度、流量和功率；
4. 将辅助设备功耗纳入系统评价；
5. 判断结论是否只适用于当前工况。
