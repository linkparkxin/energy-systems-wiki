# 10 基础运行诊断

运行诊断的目标是提出可验证的原因假设，而不是根据一个读数直接下结论。

## 常见现象

| 现象 | 可能关联因素 |
| --- | --- |
| 高过热 | 供液不足、流量偏小、换热器负荷不匹配、传感器偏差 |
| 低过热 | 供液过多、负荷突变、控制响应滞后、回液风险 |
| 高过冷 | 制冷剂积聚、冷凝器状态变化、液管换热或充注异常 |
| 低过冷 | 冷凝不足、供液闪发、制冷剂不足或测点不合理 |
| 高冷凝温度 | 排热不充分、空气或水流量不足、结垢、环境恶化 |
| 低蒸发温度 | 流量不足、负荷偏低、供液异常、蒸发器结霜 |
| 高排气温度 | 压比升高、吸气过热过大、冷却不足或压缩机状态异常 |

## 联合判断

诊断至少应同时查看高低压、过热度、过冷度、排气温度、流量、负荷和功率。还要核对传感器位置、单位、校准状态和运行是否稳定。

## 安全边界

涉及制冷剂充注、回收、压力试验和电气检修时，应遵守相关安全规范，由具备资质的人员操作。知识页面不替代设备说明书和现场检修规程。
