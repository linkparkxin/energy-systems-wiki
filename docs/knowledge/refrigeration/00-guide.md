# 00 章节导读

## 学习目标

完成本章后，应能够：

- 解释制冷系统如何把热量从低温侧转移到高温侧；
- 识别制冷剂在四个基本状态点的主要状态；
- 区分蒸发温度、冷凝温度与水侧或空气侧测量温度；
- 使用焓差、功率和系统边界计算基本能效；
- 根据过热度、过冷度、排气温度和压力进行初步诊断；
- 解释制冷循环与热泵循环的统一热力学本质。

## 前置知识

建议具备工程热力学、传热学、流体力学和湿空气基础。若基础尚不完整，可先阅读 [基础科学](/knowledge/fundamentals)，再回到本章。

## 阅读路线

**概念理解 → 状态点识别 → 图表阅读 → 公式计算 → 变工况分析 → 现场诊断**

每节先回答“是什么”，再回答“为什么”和“怎么判断”。涉及具体机组时，还需要结合厂家公开样本、设计工况和实测数据。

## 术语约定

首次出现的术语采用“中文名称（English Full Name，Abbreviation）”。本章中：

- 制冷剂状态以压力、温度、比焓、比熵、比容和干度描述；
- 过热度指实际蒸气温度高于同压力饱和温度的差值；
- 过冷度指同压力饱和液体温度高于实际液体温度的差值；
- 系统COP应明确是否包含风机、水泵和控制设备。

## 学习提醒

公式只能表达在假设成立时的关系。实际设备还会受到压降、换热不均、回油、结霜、结垢、控制响应和测量误差影响。
