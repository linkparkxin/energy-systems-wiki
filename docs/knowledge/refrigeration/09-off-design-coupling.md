# 09 变工况与参数耦合

制冷系统不是在单一额定点工作。室外温度、湿度、负荷、流量和水质变化会共同改变压力、温度、流量、功率和能效。

## 典型因果链

室外温度升高  
→ 冷凝侧排热困难  
→ 冷凝压力和冷凝温度升高  
→ 压缩比增大  
→ 压缩机功率增加  
→ 制冷量和COP发生变化。

负荷下降时，压缩机、风机和水泵可能进入变频或间歇运行状态。此时部分负荷效率、最小稳定流量、模块启停和控制死区都会影响系统性能。

## 需要同时观察的变量

- 蒸发压力和冷凝压力；
- 吸气、排气和液管温度；
- 制冷剂质量流量；
- 冷冻水、冷却水和空气流量；
- 压缩机、风机和水泵功率；
- 负荷率、环境温湿度和运行模式。

## 分析方法

先固定一个变量，再观察其他变量的变化，避免把相关变化误判为单一因素造成。工程验证应记录时间序列，而不是只保留一个瞬时读数。
