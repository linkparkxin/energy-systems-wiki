# 05 真实机组中的各种温度

## 制冷剂侧

- 吸气温度：压缩机入口附近的制冷剂温度；
- 排气温度：压缩机出口附近的高压蒸气温度；
- 液管温度：冷凝器出口至节流部件前的液体温度；
- 蒸发器入口与出口温度：用于判断节流后状态和蒸发器出口过热；
- 冷凝器入口与出口温度：用于分析放热过程和液体状态。

## 水侧与空气侧

- 冷冻水供回水温度：反映负荷侧换热量；
- 冷却水进出水温度：反映冷凝器水侧放热过程；
- 室外空气干球、湿球或湿空气状态：影响风冷和蒸发冷凝过程；
- 进出风温度：用于判断空气侧换热和流量分配。

## 模糊术语辨析

“出口温度”“冷却温度”“蒸发器温度”等说法必须补充对象、位置和测量方式。例如“蒸发器出口温度”可能指制冷剂出口，也可能指冷冻水出口，两者物理含义完全不同。

## 测量要求

记录温度时应同时保存测点位置、传感器类型、稳态时间、压力、流量和负荷。单一温度异常不能直接等同于部件故障。
