# 07 p-h 图与 T-s 图

## p-h 图

压力—焓图以压力和比焓为主要坐标，适合分析制冷量、压缩功和冷凝放热量。典型循环中：

- 蒸发器焓差对应单位质量制冷量；
- 压缩机进出口焓差对应单位质量压缩功；
- 冷凝器进出口焓差对应单位质量放热量；
- 节流前后焓值近似不变。

## T-s 图

温度—熵图有助于理解压缩过程、换热过程和不可逆损失。理想压缩可近似沿等熵方向进行，真实压缩会产生熵增。

## 阅读步骤

1. 先确认制冷剂种类和坐标单位；
2. 找到饱和液线和饱和蒸气线；
3. 标出四个基本状态点；
4. 判断各点属于过冷液、两相流或过热蒸气；
5. 读取焓、熵、压力和温度；
6. 将图上焓差与现场流量和功率对应。

不同制冷剂的物性图不能混用。图上状态点还需要与测量不确定度和实际压降相匹配。
