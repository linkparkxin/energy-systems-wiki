# 12 本章总结与学习检查

## 核心概念图

**低温侧吸热 → 蒸发 → 压缩输入功 → 冷凝放热 → 节流降压 → 回到低温侧**

分析任一制冷系统时，都应回到三条主线：

- 制冷剂状态如何变化；
- 热量和功如何传递；
- 设备、负荷、环境和控制如何耦合。

## 术语检查

应能解释：

- 饱和温度与压力的对应关系；
- 过热度与过冷度的定义；
- 制冷剂焓差与制冷量的关系；
- 蒸发温度、冷凝温度与介质温度的区别；
- 单机COP与系统COP的边界差异；
- 制冷循环与热泵循环的共同本质。

## 常见误区

- 把冷冻水出水温度直接当成蒸发温度；
- 把冷却水温度直接当成冷凝温度；
- 只看额定COP，不看部分负荷和辅助功耗；
- 根据单一压力或温度判断故障；
- 混用不同制冷剂的压力—温度关系；
- 把理想循环图线直接当成真实设备状态。

## 自测问题

1. 为什么节流前后常用等焓近似？
2. 为什么冷凝温度通常高于冷却介质温度？
3. 过热度过小可能带来什么风险？
4. 为什么系统COP需要纳入风机和水泵？
5. 室外温度升高会通过哪些环节影响COP？
6. 热泵制热时室外换热器为什么可能结霜？
