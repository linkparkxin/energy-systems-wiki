# 知识体系

Energy Systems Wiki 按照“**基础科学 → 能源技术 → 工程系统 → 控制与智能 → 工程实践 → 技术前沿**”组织知识，而不按文件来源或软件工具堆叠资料。

当前重点建设暖通空调（Heating, Ventilation and Air Conditioning，HVAC）、制冷与热泵知识域，并逐步扩展至建筑能源、综合能源、储能、数字孪生与智能控制。

## 四层知识深度

每个主题尽量回答四类问题：

1. **What：是什么**——概念、对象与系统边界；
2. **Why：为什么**——物理机理、热力过程与因果关系；
3. **How：怎么做**——设计、选型、控制、仿真和工程方法；
4. **What Next：还能如何优化**——性能边界、工程权衡与研究问题。
