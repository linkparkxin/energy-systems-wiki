# 知识体系 · Knowledge Architecture

本知识库采用“**基础科学 → 制冷与热泵 → 设备与部件 → 机组与系统 → 控制与智能 → 仿真与设计 → 工程案例 → 技术前沿**”的组织方式，重点服务暖通、制冷、能源与系统工程学习者。

**HVAC is the foundation, systems engineering is the method, energy optimization is the destination.**

| 层级 | 主要内容 | 当前入口 |

| 01 基础科学 | 工程热力学、传热学、流体力学、湿空气、守恒定律、数值基础 | [基础科学](./fundamentals) |
| 02 制冷与热泵 | 制冷循环、制冷剂、蒸发、冷凝、节流、热泵和性能评价 | [从制冷循环开始](./refrigeration-cycle) |
| 03 设备与部件 | 压缩机、换热器、节流装置、风机、水泵、阀件、管路和传感器 | [设备与部件](/components/) |

## 页面应回答的问题

每个主题尽量回答：

1. 它是什么，系统边界在哪里？
2. 为什么会这样，涉及哪些物理机理？
3. 在什么条件下成立，如何计算、测试或仿真？
4. 可能有哪些失效模式和工程权衡？
5. 还能如何优化，下一步研究问题是什么？

## 学习路径

**基础认知：** 基础科学 → 制冷与热泵 → 设备与部件  
**系统设计：** 设备与部件 → 机组与系统 → 控制与智能  
**工程研究：** 仿真与设计 → 工程案例 → 技术前沿  
**长期方向：** HVAC → 系统工程 → 能源优化
