# 节流部件

## 一句话理解

节流部件通过改变流动阻力，使高压液体降压并进入低压侧，同时调节供液量，影响蒸发器利用率和压缩机吸气状态。

## 常见类型

- 毛细管：结构简单，调节能力有限；
- 热力膨胀阀：依据过热度进行机械调节；
- 电子膨胀阀：通过控制器调节开度，适合负荷变化较大的系统。

节流部件的选型需要同时考虑制冷剂、冷凝压力、蒸发压力、压差范围、启动过程和负荷变化。

## 过热度

蒸发器出口过热度可以表示为：

$$
SH=T_{suction}-T_{sat}(P_{suction})
$$

过热度过小可能增加回液风险，过热度过大则可能导致蒸发器有效面积利用不足。控制范围必须根据制冷剂、压缩机和系统结构确定。

## 典型控制过程

1. 采集吸气压力和吸气温度；
2. 计算饱和温度与过热度；
3. 比较实测过热度和目标值；
4. 调整阀门开度；
5. 检查压缩机保护、流量和换热器状态。

实际系统还需考虑启动、除霜、低温、通讯异常和传感器故障。
