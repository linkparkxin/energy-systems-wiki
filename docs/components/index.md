# 核心部件

制冷与热泵设备的性能由多个部件共同决定。单独比较某个部件的额定效率，不能代替整机在具体工况下的系统评价。

| 部件 | 主要改变的对象 | 重点问题 |
| --- | --- | --- |
| 压缩机 | 制冷剂压力和焓值 | 效率、部分负荷、排气温度 |
| 换热器 | 制冷剂与空气或水之间的热量传递 | 传热、压降、结霜、结垢 |
| 节流部件 | 制冷剂压力和流量 | 过热度、响应和稳定性 |
| 制冷剂 | 循环工质热物性 | 压力、安全和环境影响 |

推荐顺序是：先理解制冷循环，再学习各部件，最后回到整机控制和系统能效。

每个部件主题都应回答：

- 它改变了哪一个状态变量？
- 它对上游和下游有什么约束？
- 出现故障时如何传递到整机？
- 如何通过温度、压力、流量和功率判断状态？
