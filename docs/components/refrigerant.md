# 制冷剂

## 一句话理解

制冷剂会同时影响压力等级、传热过程、压缩机排量、系统安全、环境影响和维护要求。

## 主要评价维度

- 蒸发压力和冷凝压力；
- 单位质量制冷量；
- 饱和温度与压力关系；
- 传热和流动特性；
- 可燃性、毒性和安全等级；
- 全球变暖潜能值（Global Warming Potential，GWP）；
- 与润滑油、密封材料和设备的兼容性。

## 为什么不能简单比较哪种制冷剂最好？

制冷剂性能依赖系统边界。同一种制冷剂在不同蒸发温度、冷凝温度、压缩机和换热器条件下，表现可能不同。更换制冷剂还可能影响压缩机排量、膨胀阀、充注量、压力保护和法规适用性。

## 选型顺序

1. 明确制冷或制热的温度范围；
2. 确认压缩机和换热器的允许压力；
3. 计算目标工况下的循环状态点；
4. 比较制冷量、压缩功和系统辅助功率；
5. 检查安全、材料兼容性和维护条件；
6. 核对适用标准、法规和供应条件。

本文只介绍通用判断框架，不给出具体项目的制冷剂替换建议。
