# 制冷剂

## 一句话理解

制冷剂（Refrigerant）是制冷循环中的工作流体，其热物性会同时影响压力等级、传热过程、压缩机排量、系统安全、环境影响和维护要求。

## 主要评价维度

- 蒸发压力和冷凝压力；
- 单位质量制冷量；
- 饱和温度与压力关系；
- 传热和流动特性；
- 可燃性、毒性和安全等级；
- 全球变暖潜能值（Global Warming Potential，GWP）；
- 与润滑油、密封材料和设备的兼容性。

## 为什么不能简单比较哪种制冷剂最好

制冷剂性能依赖系统边界。同一种制冷剂在不同蒸发温度、冷凝温度、压缩机和换热器条件下，表现可能不同。更换制冷剂还可能影响压缩机排量、膨胀阀、充注量、压力保护和法规适用性。

## 两相状态与干度

两相区内，制冷剂由饱和液体和饱和蒸气组成。干度（Vapor Quality，$x$）定义为两相混合物中蒸气质量占总质量的比例：

$$
x
=
\frac{m_g}{m_f+m_g}
$$

在压力确定且物性表可用时，两相混合物的比焓可写为：

$$
h
=
h_f+xh_{fg}
$$

其中 $h_{fg}=h_g-h_f$ 为汽化潜热对应的比焓差。

| 符号 | 含义 | 常用单位 |
| --- | --- | --- |
| $x$ | 干度，蒸气质量分数 | 无量纲 |
| $m_g$ | 蒸气质量 | kg |
| $m_f$ | 液体质量 | kg |
| $h$ | 两相混合物比焓 | kJ/kg |
| $h_f$ | 饱和液体比焓 | kJ/kg |
| $h_g$ | 饱和蒸气比焓 | kJ/kg |
| $h_{fg}$ | 汽化潜热对应比焓差 | kJ/kg |

### 计算示例

若两相混合物中蒸气质量为 $m_g=0.20\ \mathrm{kg}$，液体质量为 $m_f=0.80\ \mathrm{kg}$，则：

$$
x
=
\frac{0.20}{0.80+0.20}
=
0.20
$$

若同一压力下 $h_f=200\ \mathrm{kJ/kg}$、$h_{fg}=1800\ \mathrm{kJ/kg}$，则：

$$
h
=
200+0.20\times1800
=
560\ \mathrm{kJ/kg}
$$

这个计算只适用于处于两相区且物性数据口径一致的情况。

## 选型顺序

1. 明确制冷或制热的温度范围；
2. 确认压缩机和换热器的允许压力；
3. 计算目标工况下的循环状态点；
4. 比较制冷量、压缩功和系统辅助功率；
5. 检查安全、材料兼容性和维护条件；
6. 核对适用标准、法规和供应条件。

本文只介绍通用判断框架，不给出具体项目的制冷剂替换建议。
