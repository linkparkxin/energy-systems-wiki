# 机组与系统

设备最终需要与建筑负荷、室外环境、末端系统、水系统、风系统和控制系统共同运行。公共知识页面关注系统机理、评价边界和验证方法，不替代任何企业产品样本或设计文件。

## 典型主题

- 冷水机组与热泵；
- 风冷、蒸发冷和水冷冷凝方式；
- 空气处理和热湿解耦；
- 生活热水与冷凝热回收；
- 一次泵变流量系统；
- 多机组合和部分负荷运行；
- 设备级控制与系统级能效评价。
